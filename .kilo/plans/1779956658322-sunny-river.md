### ⚠️ Requires Attention: Correlation Threshold Calculation

**Issue Location**: src/lib/diversity.ts:465-474 (`computeAdaptiveThreshold` function)

**Current Implementation**:
```typescript
computeAdaptiveThreshold(): number {
  const totalFingerprints = this.fingerprints.size;
  const portfolioDiversity = this.computeAggregateCoverage();

  const baseThreshold = this.maxCorrelation;
  const diversityBonus = Math.min(0.15, (totalFingerprints / 100) * 0.05);
  const penalty = portfolioDiversity > 0.5 ? 0.05 : 0;

  return Math.max(0.25, Math.min(0.5, baseThreshold - penalty + diversityBonus));
}
```

**Problem**: As `totalFingerprints` grows, `diversityBonus` increases, which **increases** the returned threshold (makes correlation limits **less strict**). This allows more correlated alphas as portfolio grows, which is counterproductive.

**User's Concern**: "baseThreshold + diversityBonus - threshold loosened as portfolio is growing which is wrong"

**Recommended Fix**: Make threshold **more strict** (lower) as portfolio grows to avoid correlation with existing alphas.

## Plan

### Modify computeAdaptiveThreshold in src/lib/diversity.ts

Change the formula to decrease threshold as portfolio grows:

**Option 1 (Recommended)**: Make diversity penalty increase with portfolio size
```typescript
computeAdaptiveThreshold(): number {
  const totalFingerprints = this.fingerprints.size;
  const portfolioDiversity = this.computeAggregateCoverage();

  const baseThreshold = this.maxCorrelation;
  // Increase penalty as portfolio grows (more fingerprints = stricter threshold)
  const diversityPenalty = Math.min(0.15, (totalFingerprints / 100) * 0.05);
  const basePenalty = portfolioDiversity > 0.5 ? 0.05 : 0;

  return Math.max(0.25, Math.min(0.5, baseThreshold - basePenalty - diversityPenalty));
}
```

**Option 2**: Invert the diversity bonus to be negative
```typescript
computeAdaptiveThreshold(): number {
  const totalFingerprints = this.fingerprints.size;
  const portfolioDiversity = this.computeAggregateCoverage();

  const baseThreshold = this.maxCorrelation;
  // Make diversity bonus negative to reduce threshold as portfolio grows
  const diversityBonus = -Math.min(0.15, (totalFingerprints / 100) * 0.05);
  const penalty = portfolioDiversity > 0.5 ? 0.05 : 0;

  return Math.max(0.25, Math.min(0.5, baseThreshold - penalty + diversityBonus));
}
```

**Option 3**: Use exponential decay for tighter thresholds with larger portfolios
```typescript
computeAdaptiveThreshold(): number {
  const totalFingerprints = this.fingerprints.size;
  const portfolioDiversity = this.computeAggregateCoverage();

  const baseThreshold = this.maxCorrelation;
  // Exponential decay: threshold decreases as portfolio grows
  const diversityFactor = Math.exp(-totalFingerprints / 200); // Decays to ~0.6 at 100 fingerprints
  const penalty = portfolioDiversity > 0.5 ? 0.05 : 0;

  return Math.max(0.25, Math.min(0.5, baseThreshold * diversityFactor - penalty));
}
```

### Implementation Choice
**Option 1** is recommended as it:
1. Directly addresses the user's concern about threshold loosening
2. Maintains the same structure as current code (clear and understandable)
3. Provides linear increase in strictness with portfolio size
4. Keeps the same bounds (0.25-0.5) for predictability
